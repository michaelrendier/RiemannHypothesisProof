# Archive — the repository as it stood on 2026-11-03

Everything here is the repository **before the rewrite**, moved unchanged (`git mv`; history is intact). Nothing was edited or deleted.
It is kept because it is the record of how the work developed from April 2026, not because it is current.

**Read it as dated work, not as the present state.** Several documents here were written at different times, in different sessions,
by different assistants (including earlier web-API assistants), and they disagree with each other and with the code as it now stands.
In particular:

- `README.md` (v9) states in its abstract that it proves the Riemann Hypothesis; its own body names the mode identification (C1) as open.
- `PAPER.md` (v7) is the Noether-reduction draft; its Theorem 4 (a)↔(b) restates the hypothesis rather than reducing it.
- `CLAUDE_EVALUATION.md`, `SIGMA_VALUATION*.md` are assessments written by assistants at the time; they are opinions, not results.
- The `.txt` files are earlier drafts and a conversation log.

The current paper, code and notebooks are in the repository root.
