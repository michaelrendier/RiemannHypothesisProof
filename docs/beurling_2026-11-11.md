# Beurling systems: what the prime number theorem needs — 2026-11-11   :CALCULATED

Code `rhp/beurling.py`, run `experiments/beurling_probe.py` → `.json` (455 s, x to 10⁸), test `test_beurling`.
A Beurling system keeps ONLY the multiplicative structure of ℕ: a multiset of 'primes' > 1, all finite products as the 'integers', ζ_P(s) = ∏(1 − q^(−s))^(−1). No functional equation, no lattice.

## Results
1. **True primes (control).** RMS of (ψ(x) − x)/√x per decade 10⁴–10⁸: 0.218, 0.209, 0.224, 0.211. The zeros predict √(2 Σ_{γ>0} 1/(¼+γ²)) = 0.215 (25,000 zeros). Bounded, set by the zero table, not growing.
2. **Gated primes: PNT fails, by construction, and the failure is predicted to 0.005.** Take each prime p m(p) = 1 + sgn cos(τ ln p) ∈ {0, 2} times (density 1 on average). Then ψ_P(x)/x = 1 + (4/π) Σ_{j} (−1)^j/(2j+1) · Re[x^{i(2j+1)τ}/(1 + i(2j+1)τ)]: pairs of terms of size x on σ = 1 that never decay relative to x.
   τ = 1: ψ_P/x ranges over [0.084, 1.916] for x in [10⁵, 10⁸] (prediction [0.082, 1.917], max error 0.0032); τ = 3: [0.523, 1.480] (prediction [0.521, 1.478], 0.0052). True primes: [0.9989, 1.0011].
3. **Its integers still look regular.** N_P(x)/x at 10³, 10⁴, 10⁵, 10⁶, 2·10⁶: 1.324, 1.670, 1.090, 1.532, 1.656; half-range per decade 0.20, 0.29, 0.23 (the last window is partial). A visible oscillation in ln x of period 2π/τ, which in this system decays only like a small power of ln x (a log-derivation, not measured here). Beurling's theorem needs a (ln x)^(−γ) error with γ > 3/2.
4. **Random (Cramér) primes** (each n ≥ 2 a prime with probability 1/ln n; 4 seeds): RMS (ψ−x)/√x per decade 3.15 2.33 2.17 2.1 / 2.37 2.7 3.27 2.32 / 7.05 2.39 2.51 2.56 / 6.85 3.21 6.29 3.01 (median ≈ 2.6, three excursions near 7); expectation √(ln x − 2) = 2.9, 3.3, 3.6, 3.9. About ten times the true primes' 0.21. The per-decade growth is not resolved at this sample size.
5. **The non-UFD level ℤ[√−5]** (class number 2; irreducibles verified by brute force: 83 = 83 at norm ≤ 300, 236 = 236 at ≤ 1000). Prime ideals ~ X/ln X (π·lnX/X = 1.167 → 1.061, 10³ → 10⁸) but irreducible elements are denser and drifting: π_irr·lnX/X = 1.630, 1.686, 1.718, 1.741, 1.762, 1.783 (10³ … 10⁸) against ln ln X = 1.93 … 2.91. At 10⁸: 5.76 M prime ideals, 2.88 M principal, 9.68 M irreducible elements (6.80 M of them products of two non-principal ideals). The heuristic slope 1/4 per ln ln X is not reached in this range (measured 0.13–0.2): the monotone growth is measured, the constant is not pinned.

## Established (from search results; secondary sources, not the originals — check before citing)
- Beurling 1937: N(x) = Ax + O(x/(ln x)^γ) with γ > 3/2 implies the PNT; false in general at γ = 3/2 (Beurling's example continuous, Diamond's discrete).
- Diamond–Montgomery–Vorhauer (Math. Ann. 334, 2006): a system with N(x) = κx + O(x^θ), ½ < θ < 1, whose primes oscillate strongly. Broucke–Debruyne–Vindas (Adv. Math., 2020): the converse, a system satisfying the RH analogue with extreme oscillation of the integers.
- Random zeta functions (arXiv 2410.03044, via search snippet): the Cramér-type ζ continues to Re s > ½ and not across Re s = ½.

## Reading (not a result)
The PNT, and the whole critical-line picture, need more than the multiplicative structure; the integers' counting regularity, not the Euler product, carries the rest. The real primes are about ten times smoother than random ones, and their size is what the zeros on the line predict.
